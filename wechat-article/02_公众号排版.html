上个月核对一批图斑，打开 ArcMap 想加个天地图底图当参照，结果发现以前一直在用的那个插件点不动了。

图标还在，点下去没反应。换了个版本，还是一样。

那批图斑不能没有参照，干活不能停。于是就有了下面这个东西。

先说清楚，我不是不想换 ArcPro

现在新活基本都往 ArcPro 上走，这个是趋势，没什么好争的。

但老工具没那么容易退休。有些 mxd、有些老脚本、有些跟第三方对接的流程，它就是只认 ArcMap，你搬不动。还有些制图环节在 32 位环境里反而顺手（这里可以补一句你自己的具体情况）。

所以我的态度很明确：ArcPro 是主力，但 ArcMap 得能正常干活。而"能正常干活"这件事，最基础的一条就是，底图得有。

手动加过，太烦

网上教程一搜一大把，路子都差不多：注册天地图账号、申请 Key、在目录窗口里加一个 WMTS 服务器、URL 后面得手动补上 /esri/wmts、再在自定义参数里加一个 tk。

步骤复杂吗？不复杂。烦的是别的地方。

每次换台机器都要重来一遍；每换一种底图（矢量、影像、地形、注记）都要重新加一遍；而且天地图的 WMTS 就那么几套，想要 Google 影像或者 OSM 地形，ArcMap 原生根本加不上。

一台机子搞一次也就算了，反复搞谁受得了。次数多了就想，不如写个插件。

它现在能干什么

五个按钮：

添加底图 内置图源列表，带关键词筛选，双击就上图并缩放到全图
搜索 天地图地名检索，双击结果落点并缩放
图源管理 自己加 {z}/{x}/{y} 模板，能就地测连通性
设置 Key、子域、图源启停、代理
帮助 快速上手、图源说明、自定义 XYZ、常见问题

底图菜单里一共五组、35 条：

分组 条数 要 Key 说明
天地图 5 要 矢量 / 影像 / 地形 / 注记，国内直连
Esri 在线地图 9 不要 影像 / 街道 / 地形 / 海洋 / 注记，也是直连
国内图源 4 不要 高德影像 / 高德路网注记 / 高德矢量 / 腾讯矢量
境外图源 15 不要 Google / OSM / OpenTopoMap / CARTO / USGS / 维基 等，得自备代理
专题科研 2 不要 NASA Blue Marble、MODIS 真彩

最省事的是 Esri 那一组，不用申请任何 Key，装上就能用。天地图那组要先在「设置」里填 Key，注意申请的时候选浏览器端类型，别申请成服务端，不然取不到瓦片。

有个坑，必须单独说

国内图源那一组，坐标系是 GCJ-02。

这不是插件的毛病，是数据本身就这样。你把它叠到 GPS 实测点、或者 WGS84 的矢量上，会整体偏 300 到 600 米。

栅格瓦片没法在不重采样的前提下纠偏，这是硬限制，谁来都一样。要精确套合，请用天地图或者 Esri。插件在加图层的时候会弹一次提示，就是提醒这件事。

那什么时候别用它？我列一下，省得你白折腾：

你的情况 建议
要跟 GPS 实测点、WGS84 矢量精确套合 只用天地图或 Esri，别用高德、腾讯
纯离线作业，机器不联网 用不上，它靠实时取瓦片
只用 ArcGIS Pro 用不上，这是 ArcMap 的加载项
要 Google、OSM，但机器没代理 先把代理配好，不然全是空白瓦片

这能赖插件吗？不能。它就是个取瓦片的，取不到的地方我也没办法。

真正花时间的，是下面这段

天地图好办。官方就提供标准 WMTS，ArcMap 直接连就行。

麻烦的是 Google、OSM、高德这一类。它们提供的是 XYZ 瓦片，地址长这样：.../{z}/{x}/{y}.png。而 ArcMap 10.4 根本没有 XYZ 图层类型，arcpy 里没有对应的函数，想直接用它读在线服务也读不了。

所以插件在本机起了个很小的中转：把你填的 {z}/{x}/{y} 模板合成一份 WMTS 服务丢给 ArcMap，ArcMap 发过来的请求再翻译回 XYZ 去取瓦片。

对 ArcMap 来说，它连的就是一个普通 WMTS，所以缩放、拼接、缓存全都正常。这段看不懂没关系，看结果就行：以前加不了的源，现在双击就能上。

顺手记两个当时卡了很久的坑，给同样在折腾的人省点时间。

一是 ArcMap 会把参数粘到 URL 后面。本来该发 &TILECOL=421，它给你发过来 TILECOL=421service=WMTS，中间没有分隔符，直接粘上去了。查了半天以为是编码问题，最后是在模板里把一个参数放到最后当"牺牲位"，专门接住这截尾巴。

二是域名只解析一次，然后按 IP 直连，连接复用。这个是修"图层能加上、但一放大就白屏"的。每取一张瓦片都重新解析一次域名，几十张并发下去直接卡死。

装起来很快

三步：

1. 关掉 ArcMap，双击安装包，选 Install Add-In

2. 启动 ArcMap，菜单「自定义」→「工具条」→ 勾一次「天地图 Tools」

3. 「设置」里填天地图 Key，然后「添加底图」双击想用的源

第二步别漏。这个插件默认不自动展开工具条（ArcMap 启动时自动建工具条，在某些机器上会直接把进程干掉），得手动勾一次，之后 ArcMap 会记住。

安装包 200 多 K，不写注册表，不装驱动。不想用了在「自定义 → 加载项」里删掉就行，很干净。

安装包放在阅读原文，自取。

 

说回开头。这事解决的问题特别小，ArcMap 也就那样了，天地图底图也就那样了。

但每周要用好几次的东西，顺手一点是一点。老工具还在产出的日子里，别让它卡在最基础的地方。
